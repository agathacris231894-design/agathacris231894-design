## 🧬 Projetos em Destaque
 
### 🔬 Iniciação Científica - Análise de Dados Genéticos
**UFSCar Sorocaba** | 2023 - 2024
 
Projeto de IC desenvolvido para processar, analisar e interpretar dados genéticos com foco na construção de **árvores filogenéticas** para estudo de relações evolutivas entre espécies.
 
**Objetivo:**
- 📥 Tratamento de dados genéticos (sequências DNA/RNA)
- 🔬 Análise comparativa entre sequências
- 🌳 Geração de árvores filogenéticas
- 📈 Interpretação de relações evolutivas
**Tecnologias Utilizadas:**
- Python
- Biopython
- NumPy & Pandas
- Matplotlib
- Análise de dados genéticos
**Funcionalidades:**
- ✅ Importação de dados (FASTA, CSV)
- ✅ Limpeza e tratamento de dados
- ✅ Alinhamento de sequências
- ✅ Cálculo de distância genética
- ✅ Geração e visualização de árvores filogenéticas
